# Party Finder 3

This is 3rd iteration of the same idea - finding commonly liked bands on festivals.

## Current Version

Learning from the last iterations of the idea, now the project will be minimalistic - no externally authenticated users and data sources. This is supposed to be a small and simple tool to provide users with neat lists of bands, so they can discuss them, not to bypass the discussions.

## History

### Version 1

Never seen the light of day, nor was it even finished, but since it was started, it needed to be counted

### Version 2

Deployed publicly with some success, but since there was a Spotify integration, it created a lot of friction to introduce new users. It also caused some issues with modifying and improving as part of the data was not kept locally, but downloaded from Spotify API on demand.
